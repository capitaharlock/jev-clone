asimovia-decision-v1

A 17-million-parameter decision model trained from random weights. It reads a situation, a question and a set of options as raw UTF-8 bytes and returns one probability per option. This page shows how a decision flows through the network, where the training data comes from, and the curriculum loop that trained it.

1 · One decision, end to end

The whole decision is one sequence. The encoder reads the state, the question and every option together, so each option is encoded in the context of the others. The pointer head then scores each option span; its output size is the number of options in the request, not a fixed label set.

2 · Where the data comes from

Every label is computed by a program from the numbers printed on the cards, so no model and no annotator decides an answer. Splits are made on products before any question is written, which keeps every product of the benchmark out of training.

3 · The curriculum loop

Training runs as cycles. Each cycle continues the latest weights on a fresh batch, then takes a fixed exam. A rung is passed at 90%; the real rung never ends, and the best exam score is kept as the champion. Each rung adds one difficulty, so the model always trains on something it can almost do.

4 · What it does not do

The model has learned one narrow skill: reading nutrition panels and applying a comparison with an optional cap, in two languages. It has no world knowledge, no notion of price, taste or sustainability, and it was never trained on other product kinds. A hand-written rule program answers every decidable benchmark row, which is the point of the benchmark: every label can be checked against the text. The experiment shows that a tiny model trained from nothing can learn to read and compare structured text when the curriculum is right. Turning that into a general decision model would need far more data generation and far more compute than one laptop.
